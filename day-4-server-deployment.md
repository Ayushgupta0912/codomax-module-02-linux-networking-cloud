## Deployment sequence

1. Create the VM in VirtualBox.
2. Install Ubuntu Server on the virtual disk.
3. Enable and verify OpenSSH Server.
4. Update package information.
5. Install Nginx.
6. Start and enable the Nginx service.
7. Test the local HTTP response.
8. Configure NAT port forwarding to view the page from Windows.
